# Record Merges as Independent Session Projections

A Merge creates an independent target Session rather than a Branch and records its provenance by pairing an explicit Merge marker with Harness-owned Session Snapshot references in the same model step. The marker uses a known Session message event instead of adding a custom event type, while a versioned projection and durable Projection Cache expose the Merge Relation after replay or restart. This preserves Harness log compatibility and snapshot boundaries at the cost of treating Merge provenance separately from parent lineage. Retries reuse the target and durability barrier rather than creating another Session; if an earlier operation completes late, its capture is accepted only when the ordered source identities match the retry exactly.
