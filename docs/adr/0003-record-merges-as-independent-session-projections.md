# Record Merges as Independent Session Projections

A Merge creates an independent, unparented target Session rather than a Branch and records its provenance by pairing an explicit Merge marker with Harness-owned Session Snapshot references in the same model step. The marker uses a known Session message event instead of adding a custom event type, while a versioned projection and durable Projection Cache expose the Merge Relation after replay or restart. The Host re-inspects the target and every source at submission time: sources must still be non-blank, non-archived Canvas Sessions in the target directory, and a non-blank target is accepted only when its first Merge marker binds the exact same ordered sources. Browser-provided eligibility is advisory only. Once a matching capture reaches the durability commit, ownership transfers from the Remote caller to the Host; caller disconnection no longer cancels that commit, and a commit failure remains a stable persistence failure. This preserves Harness log compatibility and snapshot boundaries at the cost of treating Merge provenance separately from parent lineage. Retries reuse the target and durability barrier rather than creating another Session; if an earlier operation completes late, its capture is accepted only when the ordered source identities match the retry exactly.
